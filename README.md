# AnfragePro Server MVP v2

Benötigt nur Node.js 18+.

Start:
1. PowerShell im Projektordner öffnen.
2. `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass`
3. `npm install`
4. `npm start`
5. Browser: http://localhost:3000

Diese Version verwendet eine JSON-Datei als lokale Datenbank und benötigt kein Python und kein better-sqlite3.
